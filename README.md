# BlackDrongo Monorepo

This repository is organized into separate modules:

- `blackdrongo-selenium` - Java Selenium/TestNG/Cucumber automation framework
- `blackdrongo-ui-generator` - Spring Boot UI for project/feature/scenario authoring and execution
- `blackdrongo-ai-service` - Python FastAPI service for AI-assisted generation and healing

## Quick Start

- Framework tests: `mvn -f blackdrongo-selenium/pom.xml test`
- UI generator: run from `blackdrongo-ui-generator`
- AI service: run from `blackdrongo-ai-service`
